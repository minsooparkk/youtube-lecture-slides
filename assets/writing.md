# 화면 문구

화면 글은 원고에서 가져온다. 줄이고 나누되, 원고에 없는 사실·숫자·사례·후기는 보태지 않는다.
원고 문장이 그 위치에 그대로 맞으면 바꾸지 않는다.

## 위치별 분량

| 위치 | 들어갈 내용 | 분량 |
|---|---|---|
| `.eyebrow` | 이 장이 다루는 주제 이름 | 명사 2~10자 |
| 본문 제목 `h2` | 이 장의 결론. 제목만 읽어도 뜻이 통하게 | 한 줄이 기본, 많아야 두 줄 |
| `.sub` | 결론의 근거나 조건 | 한 줄 |
| 칸 제목 `h3` | 칸의 요점 | 한 줄 |
| 칸 본문 `p` | 설명 | 한두 줄 |
| `.box` | 장 전체를 묶는 결론 | 한두 줄 |
| `.notes` | 말로 할 내용, 녹화 대본 | 길이 제한 없음 |
| 핵심 메시지(표지·간지·한 문장·마무리) | 한 문장 | **한 줄**, `<br>` 금지 |

## 피할 문체

사용자가 과거 작업에서 반려하거나 규칙으로 정한 것들이다(Aside 메모리: 2026-09-16 쉬운 글쓰기 규칙, 2026-09-23 회사 소개 덱 피드백).

- 세 개를 나란히 세우는 리듬("빠르고, 정확하고, 쉽게")
- "X가 아니라 Y" 로 뒤집는 문장
- 글 자체를 설명하는 문장("이번 장에서는 …을 살펴봅니다", "정리하면")
- 앞 문장을 "이것", "이러한" 으로 받는 문장 — 무엇인지 다시 쓴다
- 뜻이 넓은 동사("활용", "진행", "지원") — 실제 동작(넣는다·대조한다·고친다)으로
- 목적보다 형식을 먼저 말하는 설명 — 무엇을 위한 것인지부터
- 이모지

## 줄 나눔

- 핵심 메시지는 한 줄로 쓰고, 안 들어가면 말을 줄인다. `check.py` 가 두 줄이 되거나 34px 로도 넘치면 오류를 낸다.
- 본문 제목이 두 줄이 될 때는 뜻이 끊기는 자리에 `<br>` 를 넣는다. `check.py` 가 끝줄이 4자 미만이면 "짧은 끝줄" 경고를 낸다.
- 한국어 어절 단위 줄바꿈(`word-break: keep-all`)은 템플릿 설정을 그대로 둔다.

## 제목 훑기

`check.py` 끝에 모든 장의 제목이 순서대로 찍힌다.
- 바로 붙은 두 장이 같은 말을 하면 합친다.
- 같은 말로 시작하는 제목이 줄줄이 이어지면 몇 개를 바꾼다.
- 원고의 흐름(문제 → 시도 → 막힘 → 해결 → 안내)이 제목만으로 읽히는지 본다.
