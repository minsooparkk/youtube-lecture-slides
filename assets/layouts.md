# 장 형태와 마크업

`template.html` 의 예시 장이 곧 견본이다. 아래는 언제 무엇을 쓰는지와 담을 수 있는 양.
**클래스를 새로 만들지 않는다.** 여기 없는 모양이 필요하면 가장 가까운 형태로 바꾸거나 장을 나눈다.

## 1. 장 종류 (section.slide 의 클래스)

| 종류 | 클래스 | 언제 | 담는 것 |
|---|---|---|---|
| 표지 | `cover` | 첫 장 | **제목 한 줄만**(강조는 `<em>` 한 곳). 배지·소개·강사 줄 없음 |
| 간지 | `section` | 부가 바뀔 때 | `.n`(01) · `.part`(제1부) · `h2` 제목. **목록·설명을 넣지 않는다** |
| 한 문장 | `statement` | 인용·전환·훅 | `.say` 한 줄 + `.by` 한 줄 |
| 본문 | (없음) | 나머지 전부 | `.head` + `.body` + 선택 `.box` |
| 마무리 | `closing` | 마지막 장 | 결론 제목, 한 줄, **버튼 하나**, 작성자 |

**정렬:** 표지·간지·한 문장·마무리는 가로·세로 모두 화면 가운데다. 이 장들의 제목은 `<br>` 없이 한 줄이다(길면 자동 축소). 본문 장만 왼쪽 정렬이다.

표지·마무리에는 푸터가 붙지 않는다. 본문·간지·한 문장 장에는 런타임이 푸터(강의 제목 | 쪽번호)를 붙인다.
특정 장에서 푸터를 빼려면 `data-foot="off"`.

**영상 촬영 모드(`data-video="on"`)에서는** 본문 높이가 약 300px 로 줄어든다. 줄 목록(`.rows`)은 3줄, 단계·카드는 칸마다 설명 한두 줄이 한계다. 넘치면 장을 나눈다.

## 2. 본문 장의 뼈대 — 위치 고정

```html
<section class="slide">
  <header class="head">
    <p class="eyebrow">이 장의 주제 라벨(2~8자)</p>
    <h2>결론 문장, <em>핵심 어구</em>만 파랗게</h2>
    <p class="sub">이유나 근거 한 줄(선택)</p>
  </header>
  <div class="body"> …부품 하나… </div>
  <div class="box">장 끝 결론 한 줄(선택)</div>
  <aside class="notes">발표 노트 / 녹화 대본</aside>
</section>
```

- `.head` 는 모든 본문 장에서 같은 자리·같은 크기다. 제목 크기를 장마다 바꾸지 않는다.
- `.body` 에는 **부품 하나**를 넣는다. 둘을 쌓아야 하면 대개 장을 나눌 때다. (예외: 부품 + `.src` 출처 한 줄)
- `.body` 는 남는 높이의 가운데에 부품을 놓는다. 위에 붙이려면 `class="body top"`.
- `<em>` 은 한 제목에 **한 곳**. 두 곳이면 어느 것도 강조되지 않는다.
- `.box`(네이비 띠)는 부품이 말한 것을 한 문장으로 묶을 때만. 매 장 붙이면 무늬가 된다 — 덱 전체의 1/3 이하.

## 3. 본문 부품

| 내용 | 부품 | 양 |
|---|---|---|
| 순서가 있는 절차 | `.steps.flow` (+ `style="--cols:4"`) | 3~5칸, 칸마다 h3 1줄 + p 2줄 |
| 순서 없는 병렬 항목 | `.cards` | 2~3장(`--cols:2`), 칸마다 k + h3 + p 2~3줄 + tag(선택) |
| 두 개념 대비 · 전/후 | `.duo` > `.pane` ×2 | 오른쪽이 답이면 `.pane.dark`. 칸마다 목록 2~4줄 |
| 목차 · 커리큘럼 · 순서 있는 목록 | `.rows` > `.row` | 3~5줄. 지금 부분은 `.row.now`, 지난 부분은 `.row.dim` |
| 한 문장 + 질문·항목 | `.split` (`.say` + `.qlist`) | 질문 2~4개 |
| 숫자 하나 | `.fact` | **한 장에 숫자 하나 + 출처(`.src`) 필수.** 출처 없는 숫자는 쓰지 않는다 |
| 라벨 + 설명 4개 | `.fix` | 2×2, 칸마다 b(라벨) + p 1~2줄 |
| 행·열이 있는 비교 | `.tblw` > `table.tbl` | 5행 이하. 숫자 열은 `.num`, 짚을 행은 `tr.hl` |
| 강사 소개 | `.whos` > `.who` ×2 | 現/前 + 학력 + 대표 업무 1~2줄. **연차·경력 연수는 쓰지 않는다** |
| 체크 목록 | `ul.checks` (pane·card 안에서도 가능) | 3~6줄 |
| 점 목록 | `ul.dots` | 2~4줄 |

### 단계 번호 규칙
- `.steps` 의 `.n` 은 순서가 의미 있을 때만 쓴다("1단계", "STEP 1"). 병렬 항목에 01/02/03 을 붙이지 않는다.
- 카드에는 번호 대신 `.k`(주제 라벨)을 쓴다.
- `.rows` 의 큰 번호(01, 02 …)는 목차·커리큘럼 전용이다.

### 색 규칙
- 강조색은 파랑(`--blue`) 하나. 제목 `<em>`, 라벨 `.k`, 번호 `.n` 이 모두 파랑이다.
- 네이비는 구조(간지·마무리·`.dark` 칸·`.box`). **한 장에 네이비 덩어리는 하나**(dark 칸 하나 또는 box 하나).
- 초록은 `✓` 체크에만. 빨강(`.badge.risk`, `.risk-t`)은 마감·경고에만, 덱 전체에서 한두 번.
- 칸마다 색을 돌려 칠하지 않는다.

## 4. 단계 공개 (녹화·발표용)

`data-step="1"`, `"2"` … 를 붙이면 → 키를 누를 때마다 그 순서로 나타난다. 같은 숫자는 함께 나타난다.
뒤로 가서 들어온 장은 전부 보인 상태로 열린다. PDF·검사·전체보기에서는 늘 전부 보인다.
설명 순서가 있는 steps·cards·qlist 에만 쓴다. 모든 장에 쓰면 녹화가 늘어진다.

## 5. 한 장이 넘칠 때

글자 크기로 맞추지 않고 내용을 옮긴다. 순서대로:
1. 칸 설명을 한 줄로 줄인다.
2. 칸을 하나 빼서 다음 장으로 보낸다(4칸 → 3칸).
3. 그래도 넘치면 두 장으로 가른다.

## 6. 한 장이 빌 때 (`빈 공간` 경고)

넓은 화면 가운데에 작은 카드 몇 개만 떠 있는 장이 되지 않게 한다. 순서대로:
1. 앞뒤 장과 합칠 수 있는지 본다(같은 결론이면 합친다).
2. `.sub` 한 줄이나 `.box` 결론을 보탠다 — **원문에 있는 말로만.**
3. 부품을 더 큰 것으로 바꾼다(cards → duo, 짧은 목록 → split).
4. 정말 한 문장뿐인 장이면 `statement` 로 바꾼다.
